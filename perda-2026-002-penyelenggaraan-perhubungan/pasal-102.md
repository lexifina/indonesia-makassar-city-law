# Pasal 102
(1) Pengoperasian Kereta Api yang dimulai dari stasiun keberangkatan, bersilang, bersusulan, dan berhenti di stasiun tujuan diatur berdasarkan grafik perjalanan Kereta Api.
(2) Grafik perjalanan Kereta Api sebagaimana dimaksud pada ayat (1) disusun oleh pemilik Prasarana Perkeretaapian minimal berdasarkan:
a. jumlah kereta api;
b. kecepatan yang diizinkan;
c. relasi asal tujuan; dan d. rencana persilangan dan penyusulan.
