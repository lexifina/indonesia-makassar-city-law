# Pasal 101
Pengoperasian Kereta Api menggunakan prinsip berlalu lintas 1 (satu) arah pada jalur tunggal dan jalur ganda atau lebih dengan ketentuan:
a. setiap jalur pada 1 (satu) petak blok hanya diizinkan dilewati oleh 1 (satu) Kereta Api; dan b. jalur kanan digunakan oleh Kereta Api untuk jalur ganda atau lebih.
