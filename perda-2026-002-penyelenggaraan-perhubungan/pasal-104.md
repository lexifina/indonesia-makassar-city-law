# Pasal 104
(1) Pengangkutan orang dengan Kereta Api hanya dapat dilakukan menggunakan kereta.
(2) Angkutan barang dengan Kereta Api dilakukan dengan menggunakan gerbong.
(3) Angkutan barang sebagaimana dimaksud pada ayat (2) terdiri atas:
a. barang umum;
b. barang khusus;
c. bahan berbahaya dan beracun; dan d. limbah bahan berbahaya dan beracun.
